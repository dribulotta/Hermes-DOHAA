# Security policy

Hermes-DOHAA is a pre-alpha research prototype and should not yet control irreversible, privileged, financial, medical, legal, or safety-critical actions.

Please report suspected vulnerabilities privately to the repository owner through GitHub's security-advisory interface. Do not include secrets, credentials, private transcripts, or exploitable production details in a public issue.

The current security boundary requires Hermes to run in a restricted profile and an independently enforced sandbox. The DOHAA prompt and plugin hooks are not containment mechanisms.
